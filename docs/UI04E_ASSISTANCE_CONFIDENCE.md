# UI-04e part 1 — choice assistance/confidence capture
Extends the existing choice engine before adding screen controls. Optional confidence is low/medium/high or null (not provided); it is captured before submission and locks after the first hint or answer reveal. Confidence never changes exact-match scoring or grants evidence eligibility.
Hints are an optional trusted caller-supplied sidecar keyed by selected question ID, not a new native question field. Hint IDs/labels/content are copied at creation; at most 20 hints per question are accepted in this first version. Unknown/repeated hint IDs are ignored. No supplied hints means no hint exposure can be recorded, and no hint text is invented. Actions record hint and pre-submission answer-reveal timestamps. UI controls/content display follow in the next small commit.
Submission snapshots objective: true plus fixture, confidence/time, hint exposure IDs/times, hintUsed, answerRevealed/time, firstCommitted, missedRetry and retryOfSessionId. Feedback and subsequent signal changes cannot rewrite a committed record. Exposure remains marked for the attempt even if a future UI hides its content. Next resets current signals; restart uses a new session ID and retains previously committed/missed question IDs within this selected-snapshot restart lineage. A previously unanswered question remains firstCommitted; any question missed earlier in this lineage is marked missedRetry when resubmitted. These flags do not assert a learner's lifetime first attempt or cross-session exposure history.
The evidence adapter maps recorded flags to the existing EvidenceContext contract. It does not save events, aggregate evidence or declare mastery. Later persistence/review tasks must account for durable history, publication, recency and first-per-cell policies; starting a new setup currently starts fresh local history. Existing eligibility logic excludes fixtures, assistance, repeated commits and missed retries. Objective denotes the choice scorer's method, not unassisted or approved learning evidence.
Only the choice engine and these notes change. Existing screens remain compatible with their original actions and provide no new confidence/hint/reveal controls yet. Both fixtures, open-response engine/editor, selector, setup UI, dependencies and workflows are unchanged. Open outcomes remain subjective and need separate confidence/exposure integration. No storage, AI grading or automated content processing is added.
