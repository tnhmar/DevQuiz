# DEMO-01 — small schema-backed preview
App-first scope: one original demo domain/track/concept/chapter/lesson and two choice questions in src/content/demo.en.json. Records use the existing native envelope and typed learning/question/source shapes. All learning records are draft fixtures; no book, vendor exam or factual IT teaching content is authored here.
Home connects the demo, Learn derives domain/track/chapter/lesson groups by IDs, the lesson route reads headings/paragraphs from JSON, and Practice maps option IDs into the existing exact-match scorer. Single and multi-select feedback, double-submit/next guards, restart and temporary result summary are included. Full rich block rendering, filters, ordinary content activation, true/false/open controls, persisted sessions, review, exams and computed progress still follow separately.
The demo wrapper explicitly treats the bundled original JSON as a UI fixture. The TypeScript assertion is not a runtime validator or publication gate. External content cannot be approved through it. Draft content is previewed only under a clear demo banner; no demo responses, completion, streak, SRS or mastery events are written to SQLite or user progress.
Real content authoring remains deferred until UI/logic are ready. Later material is formatted to the actual app contracts and AI-book factual claims are externally verified before publication. Runtime JSON updates remain a requirement. No automated content pipeline is restored and no Ajv/package/workflow changes are introduced by this commit.
No checks/tests/schema validation/typechecking/repository reads/CI inspection/device verification were run before preparing this commit; none will be run after pushing. Source readiness is not a claim of a successful app build.
