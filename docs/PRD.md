## 3. Levels, identities and outcomes
Beginner recognizes/explains; Intermediate applies; Advanced diagnoses and evaluates constraints; Expert designs/critiques under uncertainty. Dimensions: recall, understanding, application, diagnosis, design judgement.
Track evidence by concept + level + dimension + technology/version. Beginner answers never grant Expert evidence. Concepts are stable objectives, taught in multiple lessons. Questions assess one primary concept; supporting tags grant no progress without independently scorable components. Self-scored interview/design rubrics remain subjective.
Stable namespaced IDs for concepts, questions, options, families, lessons, sources and claims. Increment substantive revisions; never reuse identities. Equivalent renames preserve history; changed objectives/merges/splits require explicit compatibility decisions or reassessment. Preserve historical results and expose changes.

## 5. Canonical content JSON
Use result=true and data.pack/domains/tracks/concepts/content/questions/tests/glossary/sources/claims; optional examProfiles/assets/aliases. Accept JSON in .txt or .json.
content[] is flat: chapters parentId=null, lessons parentId=chapter ID. Native lessons have kind/title/index/context/revision/status, conceptRefs, typed body and questionRefs. Native questions have one central definition. Tests reference IDs or selection rules.
Legacy adapter accepts nested questions and XML text. Identical duplicate IDs become references; conflicting definitions reject with both locations. Only explicitly recognized legacy input uses first-option-correct; strip number prefixes. Legacy true_false items with non-Boolean options become single-choice with a warning. Ignore app/backend/ads/purchase configuration. Never infer approved provenance or mastery.
Native questions require explicit correct option IDs, level/dimension/type, family, primary concept, scope/revision, explanations including distractors, source/claim links, approval/status. Packs require schema/content version, language/minimum app/capabilities, author/date/rights/dependencies/sources. Profiles require issuer/credential/code/prerequisites/languages/objectives/weights/timing/navigation/scoring/source/date/lifecycle, with unknowns explicit.
V1 blocks: paragraph/heading/list/code/table/callout/figure plus inline emphasis/link/term refs; formulas accessible plain text initially. Scenario is a prompt style paired with a scorer. New question behaviours/scorers/incompatible schemas require an app update; ordinary content additions do not.
Translations share concept/question identities with basedOnRevision. Incomplete/stale French falls back visibly; corrections invalidate old translation approval. Pin exam language; never double-count translated questions as new coverage or unseen families.

## 6. Verification and authoring
External factual verification is different from editorial approval. Every AI-book factual dependency must be verified or verified-with-qualifiers against primary documentation/specifications/appropriate papers before publication. Record exact claim/book section, evidence/version/date/reviewer/qualifier and affected revisions. Owner approval cannot replace verification. Numerical/universal claims need workload qualification or narrowing.
Verification states: not checked/verified/qualified/conflicting/obsolete. Unchecked/conflicting stays staged; obsolete only in explicitly historical scopes; qualifiers appear in expected answers. Editorial draft/awaiting/approved/rejected is revision-bound. Changed facts require dependent re-review.
Authoring pipeline: objective inventory, claim extraction/verification, draft lesson/question/rubric, editorial QA, validate/package/preview. Full tooling includes shared JSON Schema/Ajv plus semantic reference/scoring checks, legacy converter, coverage/verification/translation reports. Initial preflight code is not the full validator.
Review cadence: AI APIs 90 days, cloud services 180, certification profiles 30, timeless concepts annually. Overdue does not prove falsehood, but version-bound stale items are excluded from current simulations. Verification occurs during authoring; installed study never requires live lookups. Originals/paraphrases and rights records, not copied vendor exams or assumed licensed book figures.

## 7. Pack lifecycle and safety
Receive, stage, validate, review changes, confirm activation. Structural errors/incompatible capabilities/ID conflicts/broken references/cycles/invalid answers/unsafe assets reject atomically. Valid drafts may stage but never enter learner sessions. Published explanations and factual review records are required.
Pin sessions to revisions. Rollback changes content, not progress; deletion suspends new sessions/reviews but retains archives. Reinstallation restores compatible mappings. Local file-picker import first; signed trusted HTTPS manifest later. ZIP assets must be bundled for offline use and reject traversal/executables; hashes detect corruption, not author authenticity.
V1 limits: 100 MB compressed, 300 MB expanded, 20 MB JSON, 10 MB/image and 5,000 questions/pack. Show progress/cancel/errors; interrupted imports leave active data unchanged. No third-party backend settings or private books in public git. Production must reject an empty/sample starter fallback.

## 8. Scoring, completion and event history
Explicit Submit commits an answer; taps alone do not. Exact-match multi-select, no negative marking. Save option IDs/permutation. Hints/reveals/missed-only retries/self-report never inflate unassisted objective evidence. Optional missing confidence means not supplied, not confident.
Reading, read, attempted and assessment-validated are distinct. Default lesson/topic completion threshold 90% is a transparent app heuristic. Question-free lessons can be read, not assessed. Keep earned date/revision; substantial updates show new material rather than claiming updated completion.
Open answers precede model-answer reveal and use relevant 0/1/2 rubric criteria; self/AI/human labels are distinct and excluded from objective accuracy.
Append-only SQLite events capture ID/session/question/family/revisions/pack/concept/level/dimension/scope/language/time/timezone/answer/score/policy plus assistance/exposure/fixture flags. Idempotent saves; first commitment and final exam answers separate. Retain full history by default, no automatic 5,000-event cap. Aggregates are rebuildable caches. Explicit backup/reset/deletion; no fabricated migration timestamps. Immutable attempt snapshots keep actual items/options/scoring/profile; corrections cannot silently rescore old attempts.

## 9. Progress and review
Separate completion, assessed coverage, recent accuracy, delayed recall, unseen-family performance, review workload, subjective interviews, mock results and activity. No pass probability or overall mastery percentage.
Recent window 30 days; latest eligible response per outcome cell, first eligible per cell/session. Eligibility requires objective/unassisted/before feedback/no missed retry/valid timestamp/compatible scope/non-fixture. Empty evidence is Not assessed; empty pool No assessable content. Show numerator/denominator/sample/recency/assistance/exposure/policy.
Delayed recall requires prior recorded encounter and >=24 hours; intervening recorded exposure resets gap. Outside unrecorded exposure is unknowable.
Labels per topic/level/dimension: Not assessed, Limited (<5 concepts), Needs review (<75% with enough sample), Developing, Strong recent (>=90%, >=60% coverage, >=5 concepts, latest outcomes across two local dates, >=3 delayed successes and >=3 correct unseen families), Stale. Heuristics, not scientific cutoffs; small topics stay limited. Expert uses Expert content, not arbitrary eight-concept inflation.
Review intervals 1/3/7/14/30/60 days: due correct advances; wrong/assisted/reveal resets one day; early practice does not postpone due dates. Immediate remediation is not delayed recall. Subjective queue is separate. Daily default ten questions/estimated ten minutes, adjustable: up to 60% due/30% weak/10% new, redistribute and avoid repeat families. Streak qualifies via five committed objective answers or three-rated-criteria interview; idle reading/notifications do not count. Timezone changes cannot fabricate days.

Select deterministic largest-remainder domain quotas, unique families, least-exposed preference, approved/in-scope/current items only. Full simulation requires objective coverage and >=twice configured length with adequate quotas; otherwise explicitly shorter practice. Preserve actual selection/snapshots, not seed alone. Reserved unfamiliar questions are not pass predictions.
Wall deadline continues in background/closed app; monotonic foreground countdown reconciles on resume. Expiry finalizes once, unanswered incorrect; clock anomalies mark timing compromised. First/final answers distinct, pinned language, comparable accessibility timing. Disclose all vendor differences.
Mock trend only after six comparable same-profile/scoring/timing attempts, latest-three minus prior-three means; otherwise insufficient evidence. Exposure differences visible. Confidence chart requires 20 eligible rated responses; missing ratings excluded.
