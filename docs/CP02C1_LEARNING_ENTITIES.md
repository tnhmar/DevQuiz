# CP-02c1 — typed learning-entity contracts
This small commit covers domain, track, concept, chapter, lesson and glossary shapes only. Source/claim/asset contracts are CP-02c2; test/exam-profile contracts are CP-02c3; composed-envelope integration is CP-02d.
All six entities have stable identity, positive revision, draft/published/deprecated status, source/claim references and editorial metadata. Domain and track have display order/description; track points to its domain. Concepts define objectives, prerequisites, assessed dimensions and technology scopes, not a mastery level. Chapters retain kind=chapter and parentId=null; lessons retain kind=lesson with a chapter ID and typed body/question references. Domain/track/concept/glossary require no extra kind discriminator because their collection determines their type. Glossary includes optional example and synonyms. Pack language remains pack-level, not duplicated in each entity.
Shapes reuse trusted CP-02b identifier/explanation/scope/approval definitions and CP-02a blocks. A trusted registry is supplied to Ajv; no pack-supplied schemas or dynamic downloads. Unknown fields are rejected by the final entity shape. No coercion, defaults or field stripping. Optional lesson audio is an asset/revision reference, not a claim the media exists or grants mastery.
Validators report referencesChecked=false and publicationChecked=false, including structurally valid records marked published. Question-free introductory lessons can have empty concept/question lists; reading is not objective assessment. Empty optional legacy glossary examples are omitted by the later adapter rather than converted to approved content.
CP-03 owns actual reference existence, context membership, duplicate identities, prerequisite cycles and revision compatibility. CP-04 owns factual verification/editorial publication. This task does not change the envelope, app, registry, importer, active packs or package commands.
Files: schemas/learning-entities.v1.schema.json; src/content/learning-entities.ts; src/content/learning-entity-validator.mjs; scripts/learning-entities.test.mjs.
Fixtures and tests are original contract source, not book-derived learning material. No tests, syntax/schema checks, typechecking, repository reads, CI inspections or device verifications were run for this task; none will run after pushing.
