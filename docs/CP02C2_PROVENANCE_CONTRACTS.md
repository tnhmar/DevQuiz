# CP-02c2 — source, claim and asset contracts
Scope: typed source and claim records plus image/audio/text asset declarations. This commit contains contracts and fixtures only, not factual verification, licence proof, media decoding, hash computation, importer activation or application UI.
Source types are book/official_doc/specification/paper/own. Title, locator, optional-null URL/retrieval date/version and declared rights are recorded. Source type official_doc does not make the record authoritative. Rights allow private/redistributable/unknown with a licence description and evidence source IDs; distribution is a declaration, not permission.
Claims retain source/section locator, normalized claim, one technology/version scope, external evidence IDs, verification state/reviewer/date, qualifiers, dependent entity revisions and review deadline. Machine states: not_checked, verified, verified_with_qualifiers, conflicting, obsolete. Calendar validity, actual authority, evidence sufficiency, qualifiers and revision compatibility belong to CP-03/04. Declaring verified in JSON does not prove external verification.
Assets have positive revision, lifecycle status, relative path, MIME declaration, bounded declared bytes, lowercase SHA-256 record, rights and sources. Images: PNG/JPEG/WebP, at most 10 MB, declared dimensions and alt text. Audio: MP3/M4A/WAV, at most 100 MB, EN/FR, optional-null transcript/timing references and duration. Text: TXT/JSON, at most 20 MB, transcript/timings/reference role and EN/FR. Caption is optional. Conservative ASCII path grammar disallows leading slash, dot segments, backslashes and executable/HTML/SVG suffixes in these variants; it is not a substitute for canonical archive containment, extension-to-MIME agreement, byte sniffing or actual digest validation in CP-09.
Dates check YYYY-MM-DD shape only; source/claim/asset reference existence remains unchecked. Publication, facts and licence evidence are not checked by these validators. Wrappers always return referencesChecked=false, factualVerificationChecked=false, rightsChecked=false and publicationChecked=false, even for self-declared verified/published records.
TypeScript contracts reuse technology scope from learning entities; runtime schemas reuse trusted question/block definitions. No coercion/default insertion/field stripping or pack-supplied schema. Envelope/package scripts and app remain unchanged; integration is CP-02d. Test fixtures are original declarations; no actual images/audio/book material are included or claimed to exist.
Files: schemas/provenance-entities.v1.schema.json; src/content/provenance-entities.ts; src/content/provenance-validator.mjs; scripts/provenance-entities.test.mjs.
Tests are source only. No checks, tests, repository reads, CI inspection or device verification were run before preparing this commit; none will be run after pushing. Future explicit command, not run here: node --test scripts/provenance-entities.test.mjs.
