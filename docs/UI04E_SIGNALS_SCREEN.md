# UI-04e part 2 — choice confidence and help controls
Adds a controlled confidence/help card and wires it into choice practice. Confidence is optional Not provided/Low/Medium/High and locks after the first hint, answer reveal or submission. Confidence does not change scoring. Actions flow through the existing synchronous session ref and rendered-session identity guard.
Explicit original UI-fixture hints are supplied through a separate local sidecar, limited to the selected original revision-1 demo questions. They describe reading labels and checking the requested set, not course/book facts. The engine copies them at session creation. Hint buttons show supplied labels and reveal content only after recording exposure; used buttons lock. Unsupported questions have no supplied hint, not invented fallback advice. Native fixture JSON and question contracts are unchanged.
The answer-reveal button explicitly warns that it marks the attempt assisted, then displays the requested option labels and explanation. Scored submission remains separate and may still match the requested set; feedback and completion do not call that unassisted mastery. Feedback reads captured confidence/help/retry flags; completion shows assisted and repeated-commit counts alongside the temporary total. Retry labels refer only to local selected-snapshot history, not lifetime learner history. Exposure metadata is attempt-local; cross-session/exposure history still requires later work, and every demo outcome remains excluded from learning evidence.

Both engines, selector/setup, pool adapter, both fixture JSON files, open-response editor, dependencies and workflows are unchanged.
