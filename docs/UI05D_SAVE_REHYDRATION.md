All incoming records are checked against existing registry keys and record IDs before registry mutation. Same logical outcome with changed record/ID or same ID under another key rejects; in-flight/conflicted controllers reject; an existing saved confirmation cannot be downgraded by a no-row observation. Matching controllers are reused, preserving subscriptions and state. Confirmed lookups can advance ready/unconfirmed matching controllers to saved. New controllers are prepared and registered before publishing existing-controller confirmations. This is synchronous memory registration, not a database transaction or cross-process atomicity guarantee.
Completed/discarded checkpoints may rehydrate outbox controllers without resuming an engine. Caller observations must be successful trusted repository reads, not claims from imported content. Lookup/save races still use the repository's final append checks. No listener is subscribed automatically and no timer/background retry is introduced.
