# UI-04b — demo practice-screen integration
The practice tab delegates answer selection, exact-match submission, feedback/next/finish and restart to the UI-04a engine. Session creation reads pack ID/version/language from the existing demo JSON and explicitly passes fixture: true. No demo content, dependency, workflow or assessment-policy changes are included.
The view keeps a synchronous ref to its latest engine state alongside React state. Handlers carry the rendered session identity plus question ID/revision; repeated submissions, repeated Next taps and handlers from an earlier restarted session are intended to be ignored through these guards. Restart creates a new process-local session identity and clears local answers. These demo IDs are not durable persistence identifiers.
Prompt blocks and block-based explanations reuse ContentRenderer with interactions disabled. String explanations and plain option labels retain the existing display contracts. Feedback and explanations are rendered only after submission; choices then lock. Initialization/transition failures display an unavailable state and restart control rather than inventing results.
The completion view shows correct answers and completed-question counts only. Results remain in memory, disappear on unmount and are not written to progress, review history, SQLite or exam-readiness evidence. Open responses, assistance/confidence capture, timers, ordinary content activation, durable attempts and evidence aggregation remain separate tasks. The bundled fixture still contains only the original single-choice and multi-select examples.
Source was read for this integration. The connector file read returned only a download-status message, so the existing practice-screen source and demo contracts were obtained from their source commit diff. No verification, typechecking, schema/syntax checks, tests, builds, CI inspection or device runs were performed during preparation; none will be performed after pushing. Intended behavior is not a claim of verified runtime success.
