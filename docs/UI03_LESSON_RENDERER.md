# UI-03 — shared typed lesson renderer
Scope: a shared React Native renderer wired into the demo lesson route. Native block variants: paragraph, heading, ordered/unordered list, monospaced selectable code, horizontal table with text alternative, labelled callout, literal formula with alternative, and figure with alt text/caption. Inline text/emphasis styles, explicit external-reference confirmation and term lookup sheets are included.
Code/formulas/HTML-looking strings are text, not executed or parsed as markup. Code whitespace is retained. Syntax highlighting and very-large-document virtualization remain follow-up work. Tables with unequal row widths fall back to their text alternative rather than silently discarding cells.
Term definitions require a caller-provided trusted lookup. The existing tiny demo has no glossary, so unresolved IDs show a clear unavailable message. Figures require a caller-provided registered asset resolver; the renderer never turns a book URL or raw relative asset path into a media source. Remote image URLs are rejected by the local-image guard. The caller still owns asset containment/rights/integrity; structural declarations do not prove those properties. Registered images open explicit button-based zoom controls. Pinch gestures, device accessibility and large-image memory limits have not been verified.
Existing demo JSON and questions are unchanged. The current fixture has headings/paragraphs; new block branches are implementation source, not a claim that every branch has been exercised. Practice option/feedback rendering stays unchanged for this small task. No book material, authoring pipeline, publication gate, dependency change, progress writes or workflow changes are introduced.
No checks/tests/typechecking/schema validation/repository reads/CI inspection/device verification were run while preparing this commit; none will be run after pushing. Source readiness is not proof of a successful build or runtime behaviour.
