# CP-02b — typed questions, responses and rubrics
Scope: four question variants and four submitted-response variants: single, multi, true_false and open. Native questions use central definitions, revision/family/concept IDs, level/dimension/version scope, block prompts, explanations and source/claim/editorial metadata. Scenario and code-reading are presentation tags, not extra scorers.
Choice scoring is exact_match with one point and no negative marking. Single has one correct ID; multi has a nonempty unique answer set. Boolean options have canonical true/false IDs in that authoring order; rendering may shuffle display while retaining IDs and translated labels. Open questions require a model answer, nonempty rubric with 0/1/2 anchors and explicit objective=false self-rubric scoring. Submitted blank selections/text are permitted as unanswered drafts; response-to-question matching belongs to CP-03.
CP-02a blocks are referenced through a trusted local schema registered with Ajv. No pack-provided schema, coercion, defaults or stripping. TypeScript discriminated unions describe parsed data; runtime validation is separate. Explanations/options allow literal text or typed blocks. Question validators and response validators always return publicationChecked=false.
Approval shapes can be structurally valid while unverified/unapproved for publication. CP-03 checks option/criterion identity uniqueness, correct IDs existing in options, response revision/type matching, rubric references and scope/source/claim relationships. CP-04 checks factual verification, editorial revision, stale dates and completeness of published explanations. This commit is not a grader, importer, activation gate or UI change.
